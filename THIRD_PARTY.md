Click selection runs the downloaded ONNX models with [tract](https://github.com/sonos/tract) (Sonos, MIT OR Apache-2.0), a pure-Rust inference engine. Subject and people masks on macOS use the system's Vision framework.

The complete list of Rust crates and their exact versions is in `Cargo.lock`; each crate's license applies. Using the macOS version also uses system frameworks (Core Graphics, Core Image, Vision, Metal), which are part of macOS.

## Ported algorithms (source code derived from other projects)

| Algorithm | Source | License |
|---|---|---|
| **Markesteijn demosaicing** (1-pass and 3-pass) for Fujifilm X-Trans sensors (`crates/raw/src/markesteijn.rs`) | Rust port of the X-Trans code of [darktable](https://www.darktable.org/) (`src/iop/demosaicing/xtrans.c`), © darktable developers. darktable took the method from Frank Markesteijn's implementation in [dcraw](https://www.dechifro.org/dcraw/) by Dave Coffin. | GPL-3.0-or-later |
| **Foveon processing steps of the older Sigma cameras** (SD9 to DP2x, `crates/develop/src/classic_new/dcraw.rs`: dark level and row black level, column filter, post polynomial, spatial gain, defect list, first-layer sharpening, coring curve, chroma smoothing, colour coring, recursive chroma smoothing) | Rebuilt after the functions `foveon_interpolate`, `foveon_avg`, `foveon_make_curve` and `foveon_apply_curve` of [dcraw](https://www.dechifro.org/dcraw/) 9.28 (revision 1.478) by Dave Coffin. dcraw's Foveon functions may be redistributed under the GPL version 2 or later. | GPL-2.0-or-later (used under GPL-3.0) |
| **RCD demosaicing** ("Ratio Corrected Demosaicing") for Bayer sensors (`crates/raw/src/rcd.rs`) | Rust port of the code in [RawTherapee](https://www.rawtherapee.com/) by Luis Sanz Rodriguez and Ingo Weyrich; original algorithm [LuisSR/RCD-Demosaicing](https://github.com/LuisSR/RCD-Demosaicing) | GPL-3.0-or-later |
| **Tone curve matched to the camera JPEG** ("Match camera JPEG", `crates/raw/src/learn_look.rs`, `matched_curve`) | Idea of RawTherapee's "Auto-Matched Curve" (`rtengine/histmatching.cc`, © 2018 Alberto Griggio): match the brightness histogram of the neutral development to the camera's own rendering of the same shot. Own implementation; no code taken over. | GPL-3.0-or-later (idea only) |

The changes made in each port are listed at the top of the respective source file. Several other image operations follow formulas published by darktable and RawTherapee; the source is noted in the code comments.
